# 渠道状态分组鹈鹕检测（本地开发版）

## 入口与权限

- 管理后台：渠道管理 → 降智检测（`/admin/channels/quality-tests`）。
- 配置对象是持久化的 **分组 ID**，不是可变的监控名称、API Key 或上游账号名。
- V2 渠道状态在带分组 ID 的矩阵行旁展示入口；V1 监控没有分组 ID，使用独立的分组检测入口区，避免按名称猜测绑定。
- 配置默认禁用且客户不可见。客户权限：`hidden`（管理员）、`view`（仅结果）、`run`（可发起）。
- 用户列表、历史、源码、任务提交都校验该用户当前可用分组和当前开放配置。修改配置只允许管理员。
- 客户响应不包含上游账号 ID、映射目标模型、发起人 ID。客户不能指定账号、密钥、URL、提示词或任意模型。

## 检测范围与结论

仅支持 OpenAI 平台的 API Key 上游账号，固定 `gpt-6-astra` / `gpt-6-sol` 两个用户侧模型名。优先级较小的可调度账号优先；也可固定分组内的某个 API Key 账号。OAuth 账号不走本功能。

这是 **直接上游诊断**，不是分组网关全链路测试：复用账号代理、TLS 配置、账号模型映射和请求头，不执行分组提示词注入、渠道级映射、用户计费或组合路由。因此它用于观察上游生成质量，不能据此证明分组真实业务链路完全正常。

支持显式选择 Responses / Chat Completions；不做协议失败后的自动重试或自动切换账号，避免重复消耗额度。使用非流式请求，最长 5 分钟，输出 token 上限 16000。上游不支持非流式、对应模型或长度参数时，会记录失败。

## 定时调用模型（不是结果轮询）

每个分组可以单独开启自动检测，默认 `auto_enabled=false`，间隔默认 600 秒。管理员可输入 10 分钟到 365 天，快捷选项为 10/30/60/120/360/1440 分钟。客户不能修改计划。开启自动检测不会自动开放客户权限。

每个选中模型独立执行；选中两个模型意味着各自一次上游付费请求。保存配置后等待所选间隔才首次调用，不立即消耗额度。计划保存在数据库，浏览器关闭后继续工作。后台每 30 秒检查到期计划，该检查本身不调用模型。全站只运行一个检测任务，忙时延后；每个到期模型最多执行一次，不补跑停机期间漏掉的历史次数。

领取计划时从当前时间推进下次时间，提交失败也等下一周期，不进行高频付费重试。自动任务完成后，下次时间至少为完成时间加检测间隔，并尊重冷却；因此实际间隔可以比配置更长。数据库事务级调度锁防止多副本重复领取，并在最终任务预留时再次检查自动开关。禁用或保存计划会移除/重新安排未来任务，已发出的请求仍可完成。

固定内联 HTML/SVG 动画提示词版本 `pelican-animation-v1`。检测仅检查响应成功、完成状态以及完整 HTML/SVG 产物；生成完成仍需管理员人工比较结构和动作，**不是自动“不降智”判定**。不修改渠道健康状态或调度开关。

## 资源与隔离

- PostgreSQL 事务锁 + 唯一部分索引限制全站单任务；另复用正常账号并发槽，不挤占已满账号。
- 默认每个分组/模型检测结束后冷却 10 分钟，可配置 5 分钟到 24 小时；管理员也不可绕过。
- 同模型最近 5 条历史；响应最大 1MiB，存储源码最大 512KiB；历史轮询不读取源码。
- 后台异步生成，弹窗关闭不取消已经提交的任务。过期运行记录在读取时显示中断，在下次提交时回收。
- 弹窗结果轮询默认 5 秒，可选择 3/5/10/30/60 秒或仅手动刷新，设置保存在当前浏览器。轮询只查任务，不重复调用模型，也不改变检测冷却时间。后台页面隐藏时暂停，关闭或切模型会取消旧查询。临时查询错误指数退避，连续 3 次失败暂停；401/403/404 立即停止重试。
- 已完成记录缺少源码时，刷新会重新加载源码，避免一次网络错误导致动画一直空白。
- 原始源码通过文本展示和复制。预览只进入 `sandbox="allow-scripts"` 的不透明来源 iframe，禁止共享宿主登录状态、弹窗、顶层导航等；注入 CSP 禁止网络请求、外部脚本/样式、嵌套框架等，并剥离外部资源、表单、刷新、base 和链接跳转。
- 浏览器负责动画，无服务端浏览器、模型推理或高频自动巡检。
- 上游可能收费或扣额度；本功能不扣普通用户余额。
