# Movo 视频接入与迁移

本次修改仅在代码中完成，不自动部署、不修改线上渠道或历史账单。

## 协议

账号平台 `video`，类型 `apikey`，协议 `movo_video`。Base URL 仅允许
`https://movoapi.top`、`https://www.movoapi.top`，以及它们的 `/v1` 地址。
创建和查询使用 `/v1/videos`，站内用户继续使用本站 `/v1/task/submit` API。
禁止自动重发提交结果不确定的创建请求。

- MiniMax-H3：seconds 为字符串，素材使用 metadata.content 对象，按秒、768P、1–15 秒；9图/3视频/3音频，总共最多12个。音频生成没有已确认的静音开关，界面说明由上游决定。
- seedance2.5-yx-stable：seconds 为整数，素材使用 reference_images/videos/audios URL 数组，按条、4–30秒，480P/720P/1080P；30图/10视频/10音频。支持声音和 FACS；显式传 FACS，默认开启，剧本保存该设置。
- seedance-2.0：按站点所有者要求，不接入、不导入、不售卖。

当前工作台使用参考素材模式，不提供上游首尾帧专用模式；镜头“构图参考”作为普通参考图片使用（旧剧本 first_frame 字段仍兼容）。
素材数量、时长、清晰度和提示词长度会在计费前校验。素材编码、画面尺寸和实际视频/音频时长仍由上游校验，不能将本地格式测试视为所有素材都可用。

## 结果

优先使用响应中的公开 HTTPS 成片地址。需要鉴权的 content 下载由服务器完成；
302 仅返回安全的公开HTTPS地址，不携带密钥跟随跳转。返回200的MP4保存到站内素材库，
单片上限100MB，计入每用户200MB素材容量。保存失败进入人工核对，不伪造成功、不自动重发。
生成结果按任务ID保存，结算重试不会重复占用素材容量。

## 定价

`GET /v1/models`只表示密钥的模型权限，不能证明实际成本。
不能使用旧LaneAI价格或Movo公开基准价代替当前账号分组实际扣费。
导入模型后清空旧价格与规则，并关闭渠道，要求填写已确认的成本。

后台提供“按成本加价20%计算售价”：

`站内售价 = round(人民币实际成本 × 1.20 ÷ 每1站内额度对应人民币, 2)`

成本、售价和换算值有明确单位。高级档位和素材附加费也进行同样换算。
计算仅修改待保存的表单，不直接改线上售价；两位小数无法保留正利润时阻止计算。
最终视频售价不再叠加聊天分组倍率。20%指成本加价，并非销售额毛利率20%。

## 部署前

1. 核实Movo账号实际分组扣费、币种和本站充值换算值，填写成本，计算并审核售价。
2. 让旧渠道停止接收新任务，检查未结算任务并按真实状态处理。保留旧任务和账单。
3. 备份数据库和部署配置；新建Movo账号，不覆盖旧账号的凭证。
4. 部署新版本后绑定新账号、导入模型、填写价格和并发；检查后开放。
5. 进行已获预算授权的真实文生视频、图片/视频/音频参考生成验收。

目前验证包括本地请求序列化、模型目录读取、参数校验、结果解析、下载跳转安全、
输出保存幂等及定价计算。没有完成Movo收费成片的端到端验收。
